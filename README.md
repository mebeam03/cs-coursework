# C# Programming Fundamentals

A collection of introductory C# programming exercises focused on developing foundational programming skills. These examples cover basic program structure, variables, data types, string comparisons, user input, arithmetic operations, and console output formatting.

## Repository Contents

### Unit 1: Introduction to C#

Introduces the basic structure and syntax of C# console applications.

| File | Description |
|---|---|
| AnyLegalClassName.cs | Demonstrates basic class structure and the `Main()` method. |
| CLassWIthOneExecutingLine.cs | Introduces comments and console output statements. |
| FirstClass.cs | Creates a simple C# program that displays a message. |
| ThreeLinesOutput.cs | Demonstrates multiple console output statements using `WriteLine()`. |

### Unit 2: Variables, Data Types, and Expressions

Expands on foundational concepts through variable declarations, string operations, calculations, and formatted output.

| File | Description |
|---|---|
| CompareNames1.cs | Compares string values using the equality operator (`==`). |
| CompareNames2.cs | Demonstrates string comparisons using `Equals()`, `CompareTo()`, and `Compare()`. |
| DisplayForFigure08.cs | Displays integer values using formatted console output. |
| DisplayForFigure09.cs | Demonstrates field widths and alignment in console output. |
| DisplayForFigure13.cs | Illustrates incompatible numeric data types through an invalid assignment. |
| DisplaySomeMoney.cs | Introduces numeric variables and console output. |
| DisplaySomeMoney2.cs | Combines descriptive text and numeric values. |
| DisplaySomeMoney3.cs | Demonstrates formatted output using numbered placeholders. |
| DisplaySomeMoney4.cs | Reuses variable values within a formatted output statement. |
| InteractiveSalesTax.cs | Accepts user input and calculates sales tax using a constant 6% rate. |

## Programming Concepts Demonstrated

- C# syntax, classes, and the `Main()` method
- Variables, constants, and basic data types
- String comparisons and Boolean expressions
- Console input and output
- Numeric calculations and arithmetic operators
- Data type conversion
- String formatting and alignment
- Code comments and program readability

## Technologies

- **Programming Language:** C#
- **Platform:** .NET
